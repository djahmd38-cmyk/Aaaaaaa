# Dental Lab APK — Phone-only build

1. Create a GitHub repository.
2. Upload the contents of this project (not the outer ZIP folder).
3. Open the **Actions** tab.
4. Select **Build Dental Lab APK**.
5. Tap **Run workflow**.
6. When the run finishes, open the run and download the **DentalLab-APK** artifact.
7. Extract the artifact ZIP and install `app-debug.apk` on Android.

The supplied HTML app is bundled as an Android WebView app. Its local storage and JavaScript-based timer are preserved.
